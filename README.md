
# 📧 Spam Email Classifier (ML Project)

A machine learning model that detects spam emails using TF-IDF vectorization, Naive Bayes classification, and rich visualizations to analyze text patterns and classify messages with high accuracy.

---

## 🚀 Project Overview
This project builds an intelligent **Spam Email Classifier** using Natural Language Processing (NLP).  
It uses the **SMS Spam Collection Dataset**, performs text preprocessing, generates wordclouds, extracts important features, and trains a **Multinomial Naive Bayes** model to classify messages as **spam** or **ham**.

---

## 🧠 Features
- TF-IDF text vectorization  
- Multinomial Naive Bayes classifier  
- WordCloud visualization for Spam & Ham messages  
- Confusion Matrix heatmap  
- ROC Curve + AUC Score  
- Top spam-indicative keywords  
- Clean and modular Google Colab notebook  

---

## 📂 Dataset
The project uses the popular open dataset:

**SMS Spam Collection Dataset**  
Source: UCI Machine Learning Repository  
Format: Tab-separated file with *label* and *message*

---

## 📊 Model Performance
The classifier achieves:

- **High accuracy (≈ 97–99%)**  
- Excellent precision and recall for spam detection  
- Strong ROC-AUC score
